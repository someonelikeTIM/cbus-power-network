# Contribute to CBUS Power

Found a missing connection, a better source or a mistake? [Open an issue](https://github.com/someonelikeTIM/cbus-power-network/issues/new/choose). Questions and general feedback also go through [GitHub issues](https://github.com/someonelikeTIM/cbus-power-network/issues).

## Evidence and corrections

Include the record link or ID, the edition examined, the proposed change and a public source. A page, section or paragraph reference helps others check the claim. Explain what the source establishes and any uncertainty about the amount, date or identity.

A verified dated archive is useful; a checked original is welcome when an archive is unavailable. Sources can support, qualify, contradict or supersede a claim. An accepted correction should retain a reason, attribution, before/after values and its review history. Similar names alone are insufficient for merging people or organizations.

Public issue forms are available for [corrections](https://github.com/someonelikeTIM/cbus-power-network/issues/new?template=evidence-correction.yml), [new evidence](https://github.com/someonelikeTIM/cbus-power-network/issues/new?template=new-evidence.yml), [bugs](https://github.com/someonelikeTIM/cbus-power-network/issues/new?template=bug.yml) and [questions](https://github.com/someonelikeTIM/cbus-power-network/issues/new?template=question.yml). Proposed changes remain separate from accepted records until reviewed.

## Code and design

Describe the problem and resulting behavior in your pull request. Screenshots help with visual changes. Run `npm run build` and `npm test`; include the checks performed and any limits. Preserve stable IDs, source qualifications, date precision, keyboard access and ordinary document scrolling. See the [development guide](https://github.com/someonelikeTIM/cbus-power-network/blob/main/docs/DEVELOPMENT.md).

## Public submissions and reuse

Issues and pull requests are public. Share public evidence and use a public name or pseudonym for attribution. Private contact details, unpublished tips and confidential documents belong outside this repository. This project currently has no confidential intake channel.

By contributing, you agree to license your original code/documentation contributions under MIT and your original curated-data contributions under CC BY 4.0. Identify third-party material and its terms; it is excluded from those grants. See [data licensing](https://github.com/someonelikeTIM/cbus-power-network/blob/main/DATA-LICENSE.md).
