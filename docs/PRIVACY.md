# Privacy

Campaign ledgers contain names, amounts, dates and public employer/occupation information reported in official disclosures. Postal addresses and contact fields are excluded, and contact information in descriptive fields is removed. Original downloads and scans are not redistributed. Source links can lead to originals containing additional information under the publisher's own terms. Totals by reported name do not establish a unique donor identity.

The explorer has no account system, analytics, advertising or submission backend. Its JavaScript keeps display preferences and named saved views in local browser storage. Open tabs are retained in the browser's session storage for reloads. Selected records, filters and pins appear in the page URL so views can be shared. Current-view downloads and exported workspace files are created in your browser.

Saved views and research paths can reveal the people, organizations and topics you are exploring. Research notes stay in browser storage and exported files; shared page URLs contain record IDs, rather than your notes. A research-path export includes your title, notes, selected steps and their source records. Imported files are read locally and validated against known record IDs; embedded records cannot replace the website's dataset. They are not uploaded to a project server. Removing a named view removes it from this browser's saved-view list; copies you exported remain wherever you saved them.

GitHub Pages hosts the site and processes requests under [GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). Opening source links takes you to the source publisher or the Internet Archive, with their own policies.

Contributions, questions and contact go through public GitHub issues and pull requests. Those submissions are visible publicly. This project has no confidential tip channel.

The dataset describes public roles and sourced public-interest records. It does not publish contributor home addresses, personal contact lists, credentials or private files. To raise a record-specific concern, use the [correction form](https://github.com/someonelikeTIM/cbus-power-network/issues/new?template=evidence-correction.yml) with a public record ID and the minimum information needed to explain it.
